PixArchive

Archive every gallery.

PixArchive wraps gallery-dl in a polished desktop UI — smart URL detection, live download queues, per-site auth, and a full theme system.

Quick Install
bash — install & run
$ git clone https://github.com/shubh-ssj/pixarchive.git
$ cd pixarchive
$ pip install -r requirements.txt
$ python main.py
# gallery-dl is auto-detected and installed on first launch

Capabilities

Everything you need.
Nothing you don't.

01
🔗

Smart URL Detection

Paste any URL and instantly see the site name, supported content types, and auth requirements — no guesswork.

02
📋

Clipboard Watcher

Switch to PixArchive with a URL on your clipboard and it pastes automatically. Zero friction from copy to queue.

03
🎛️

19 Built-in Presets

One-click presets for every major platform and workflow — archive, images-only, slow connection, dry run, and more.

04
📊

Live Queue & History

Job cards with real-time progress bars, ETAs, and file counts. Right-click to view logs, retry, cancel, or open the output folder. SQLite-backed history with CSV/JSON export.

05
🔐

Per-site Auth

OAuth, cookies, and credentials managed per site. Extract cookies straight from your browser — no manual config files needed.

06
🖱️

Drag & Drop

Drop URLs or a plain-text file of URLs directly onto the window. Batch-queue entire link lists in one gesture.

07
🔧

Full Options Control

Output directory, filename patterns, filters, rate limiting, retries, proxy, and a raw JSON editor for power users.

08
🚀

First-run Wizard

Detects gallery-dl on launch and installs it automatically if missing. Migrates settings from older GUI versions seamlessly.

09
🔔

System Tray & Notifications

Runs quietly in your system tray with desktop notifications for completed downloads and background gallery-dl update checks.
